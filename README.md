# brunch & wine 🥂

A simple interactive picker to plan the perfect brunch and wine tasting day.

## What it does

Walks through 3 quick questions:
1. **Time** — pick a brunch slot between 10:00 am and 1:00 pm
2. **Restaurant** — choose from Bloom, The Breakfast Club, or Sweet Maple
3. **After brunch** — pick a wine option (local winery, Stella Rosa Red, or Stella Rosa Black)

At the end, you can email the plan directly to a friend.

## Hosting on GitHub Pages
